# Kodestandarder

- Skriv enkel, læsbar kode med konsekvent indrykning og beskrivende navne.
- Brug semantisk HTML, almindelig CSS og JavaScript uden unødvendige afhængigheder.
- Hold HTML, CSS og JavaScript i separate filer. Undgå gentagelser og unødvendig kompleksitet.
- Sørg for responsivt layout, tastaturbetjening, tydelige fokusmarkeringer og god kontrast.
- Respekter brugerens indstilling for reduceret bevægelse ved animationer.
- Brug kommentarer til at forklare hensigten, når den ikke fremgår af koden.
- Kontrollér links, interaktioner og layout på mobil og computer. Ret konsolfejl.
- Vælg selv den kreative retning, medmindre opgaven angiver andet.
